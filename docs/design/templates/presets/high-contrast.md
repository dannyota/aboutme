# high-contrast

Status: **Draft v1** (2026-08-12). Not approved.

Near-black on white, one saturated blue, strong hierarchy — for low vision, poor
screens, and a tired office laser. Every text role clears WCAG **AAA** (7:1
normal, 4.5:1 large), not the 4.5:1 AA floor `colors.md` §5 guarantees.

## Defining decisions

| Token                          | Value                              | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `font.family`                  | Inter                              | large x-height, open apertures, and near-uniform strokes that survive degraded raster output; this preset chooses those traits without restricting other catalog families                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `colors`                       | `#000000` `#141414` `#ffffff`      | headings and name at maximum ink; body just off pure black to cut glare over long paragraphs. Both are achromatic (R=G=B), so a colour laser prints text from the K channel alone with no CMY registration fringing — a blue-tinted near-black like `#0f172a` does not have that property. The ceiling on `text` is `#212121`; past that the derived `--color-meta` drops below 7:1.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `spacing`                      | 36 / 20 / 1.6, margin x 18 y 16 mm | line height 1.6 clears SC 1.4.8's 1.5 with margin. Section and entry gaps sit 1.8× apart so proximity carries grouping, and the derived `--gap-heading` (14.4 px) lands below `entryGap`, binding a heading to its own section rather than floating it between two. On page margin, `x` sets the measure and is a legibility control while `y` only sets capacity — hence the asymmetry.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `heading`                      | `uppercase`, rule on               | `--fs-heading` is 1.10× base and `--fs-title` 1.00×, both weight 700 — 1.8 px apart. Case plus the 0.06em tracking is the only separation left between those two levels, and the rule is a second, redundant cue. `text-transform` is presentational, so the DOM, screen readers, and `/{slug}.md` keep the user's casing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `header`                       | `left`, `stacked`, `outline`       | left gives a constant edge to return to on every line. At 4× magnification a viewport shows about a quarter of a line, so an inline contact run forces horizontal panning — the worst case for magnifier users; stacking costs ~5 lines of page and is worth it. This preset argued for a filled glyph on silhouette grounds; `tokens.md` §3.4 removed `solid` because lucide ships no filled family, so the choice was outline or nothing, and outline answers the argument on its own terms: the stroke is a fixed fraction of `--icon-size` (1 em), so base 18 rasterises it at ~1.5 px against ~1.2 px at base 14 — the heaviest stroke any preset in the set gets, and above the 1 px hairline `geometry.md` §6 already trusts to survive 96 dpi. The per-type shape cue is unchanged, since filled and stroked are the same lucide mark. And `stacked` puts each detail on its own line with its own text label (ADR 0013), so the icon is the redundant cue here, never the carrier. |
| `layout`                       | 1 column, `keep`, no surface       | one flow is one reading order, in the DOM and in the PDF tag tree. Also forced: `--sidebar-ratio` (32%) is calibrated to base 14, so at base 18 a sidebar is ~24 characters wide and every skill name wraps. No tinted surface, because reversed text needs the printer to lay solid ink — a failing cartridge turns white-on-blue into white-on-streaks, while dark-on-white only gets lighter. `colors.surface` is therefore omitted.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `sectionDisplay`, `dateFormat` | `text`, `Mon YYYY`                 | a 4 px bar and a row of 7 px dots sit below the size at which a low-vision reader resolves a count, and `contract.md` §5.6 gives 0–5 no label vocabulary, so neither has a text alternative — the level is not rendered at all, one datum dropped rather than shown in a form some readers cannot perceive. `Mar 2019` is likewise recognised as a word shape where `03/2019` has to be parsed, and its month table is a fixed English array, so it stays deterministic.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## Contrast, computed

Surface is `#ffffff` throughout. **AA** is `colors.md` §5's floor, **AAA** this
preset's target. Every §5 clamp is a no-op here, so snapshots pin authored hex.

| Role and value                                       | Size class                                   |      Ratio | AA    | AAA   |
| ---------------------------------------------------- | -------------------------------------------- | ---------: | ----- | ----- |
| `--color-heading` `#000000`                          | 19.8 px bold heading, 36 px name — **large** |  **21.00** | 3 ✓   | 4.5 ✓ |
| `--color-body` `#141414`                             | 18 px title, subtitle, body — normal         |  **18.42** | 4.5 ✓ | 7 ✓   |
| headline, whichever role it takes                    | 20.7 px at 400 — normal, **not** large       | 18.42–8.19 | 4.5 ✓ | 7 ✓   |
| `--color-meta` `#4f4f4f` (text mixed 25% to surface) | 16.2 px — smallest text on the page          |   **8.19** | 4.5 ✓ | 7 ✓   |
| `--color-accent-text` = `--color-link` `#0b3fd6`     | 18 px — normal                               |   **7.79** | 4.5 ✓ | 7 ✓   |
| `--color-accent-solid` `#0b3fd6`                     | non-text                                     |       7.79 | 3 ✓   | —     |
| `--color-on-accent` `#ffffff` **over** the accent    | text on a fill; unused by this preset        |   **7.79** | 4.5 ✓ | 7 ✓   |
| `--color-rule` `#9db2ef`                             | decorative                                   |       2.09 | 1.5 ✓ | —     |
| `--color-track` `#ced9f7`                            | non-text; never rendered here                |       1.41 | 3 ✗   | —     |
| accent on `--color-body`, not on the surface         | link inside a paragraph (WCAG G183)          |       2.37 | 3 ✗   | —     |

| Failing row     | Why it is structurally unreachable, not a preset mistake                                                                                                                                                                                                                                                                                                    |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--color-track` | the role is the accent mixed 80% toward the surface, so on white it cannot exceed **1.61:1** for _any_ accent — that is its limit at accent `#000000`. No template can make the unfilled part of a level bar meet the 3:1 non-text floor against the page. Moot here, since both widgets are `text`. Raised as contract pressure rather than worked around. |
| link on body    | provably unsatisfiable together with AAA. AAA on white needs accent luminance ≤ 0.10; G183 needs `L_accent + 0.05 ≥ 3 × (L_text + 0.05)`, hence `L_text ≤ 0`. The two meet only at pure-black text with an accent at exactly 7.00:1 and 3.00:1 — a knife edge that 8-bit rounding alone breaks. AAA wins, and the underline below is the real fix.          |

## Base size: 18

| Constraint                                        | Derivation                                                                                                                                          | At base 18                      |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| Section headings should be WCAG **large text**    | `--fs-heading` = 1.10 × base at weight 700; the threshold is 18.66 px bold, so base ≥ 17                                                            | 19.8 px, large, with margin     |
| The smallest text on the page should clear ~11 pt | `--fs-meta` = `max(0.9 × base, 9px)` — dates and place, the first thing a low-vision reader loses                                                   | 16.2 px = 12.2 pt (14 → 9.5 pt) |
| Measure ≤ 80 characters (SC 1.4.8, AAA)           | 80 chars ≈ 40 em at ~0.5 em average advance; A4 at `pageMargin.x` 18 mm is 174 mm ≈ 658 px, so 658/40 ≈ 17 px is the floor. Letter gives ~76 chars. | ~73 chars, inside 66–75         |

Body is 13.5 pt: over the 12 pt clear-print floor, under the 16 pt where a
resume stops reading as one. It costs ~35 lines per A4 page against ~51 at
base 14.

## Resolving the saturated accent at AAA

A full-chroma accent at 7:1 on white is hue-bound: AAA caps luminance at 0.10,
and sRGB's primaries sit at 0.2126 red, 0.7152 green, **0.0722 blue**, so blue
alone starts below the ceiling. A gamut scan puts peak chroma near hue 264;
`#0b3fd6` is **7.79:1** at chroma 0.234, an sRGB maximum for that contrast.

| Falls out for free | Consequence                                                                                                                                                                                                                                                                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Luminance symmetry | `contrast(white, X)` does not depend on order, so white over the accent is the same **7.79:1**: `--color-on-accent` resolves to AAA, not the required 4.5:1. Greyscale conversion preserves luminance too, so a mono laser prints the accent as `#525252` at **7.7:1**, where a mid-tone red or teal at similar apparent saturation collapses to roughly 4:1. |
| Colour vision      | blue keeps its identity under protan and deutan deficiency, where a dark red reads as near-black. And because every accent-bearing role is ≥ 7:1, no renderer decision about _where_ the accent lands can breach the floor — sparing use is style here, not safety.                                                                                           |

## Nearest siblings

| Sibling      | It optimises                        | Visible difference                                                                                                                                                                                                                                                                 |
| ------------ | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mono-print` | no colour at all                    | one accent survives here, because a link, a rule, and an icon should be identifiable by more than position. It is chosen by luminance, so it degrades to the greyscale `mono-print` starts from without giving up the on-screen cue.                                               |
| `ats-plain`  | tokenisation — a parser has no eyes | base 18 against a conventional 11–14, stacked contacts over inline, uppercase headings with a rule, 18 mm side margins that shorten the measure. This preset spends page count on legibility; a parser-first preset cannot. In one glance it is a third larger than the whole set. |

## Unexpressible intent

| Wanted                   | Why it is out of reach                                                                                                                                                                       |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Underlined links         | `text-decoration` is renderer-owned, so the G183 row cannot be fixed from a preset. Recommend the renderer underline links in every template — the fix is renderer-wide, not per template.   |
| Character disambiguation | Inter's `I`/`l`/`1` need its `cv`/`ss` alternates through `font-feature-settings`, which is not a token. The one legibility loss in this preset.                                             |
| Reader-relative sizing   | `baseSizePx` is an absolute integer, so the public page ignores a reader's browser font-size preference. A rem-based base would serve this audience better than any value a preset can pick. |
| Paragraph spacing        | SC 1.4.8 also wants paragraph spacing ≥ 1.5× line spacing. That is the `<p>` margin inside rich text: renderer-fixed, and not derived from `spacing.*`.                                      |
