# 0001 — AGPL-3.0 license

Status: Accepted (2026-08-01)

## Context

The project must stay open source even when third parties run it as a hosted
service, and the author's attribution (copyright notices) must be preserved.
GPL-3.0's copyleft does not trigger for SaaS operators (no distribution);
permissive licenses (MIT/Apache-2.0) allow closed forks.

## Decision

License the repository under **AGPL-3.0-only**. Network use counts as conveying:
operators of modified versions must offer their source to users.

## Consequences

- Hosted competitors must publish their modifications.
- Copyright/attribution notices must be preserved by all forks.
- Some enterprises avoid AGPL dependencies; acceptable — this is a product, not
  a library.
