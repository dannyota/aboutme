# Documentation standards

These standards define how repository documentation and code comments divide
responsibility. They apply to new work and to files being changed.

- [Engineering documentation and comments](engineering.md)
- [Documentation map](../README.md)

Proposed and accepted design decisions belong in [ADRs](../adr/). Intended
architecture belongs in [the design](../design/). Execution state belongs in
[plans](../plans/). A code comment is not a substitute for any of them.
