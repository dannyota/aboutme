# v0.5.x roadmap

Status: planned on 2026-09-24; v0.4.7 is live. The owner set the v0.5 theme:
users must see what readers get. aboutme renders one resume as a web page that
adapts to the reader's device and as an A4 PDF. Competing builders show only the
PDF layout. The editor and the template library must show both forms, and the
PDF view must match the downloaded file.

## Starting point

- The homepage shows a fictional sample (Ada Lovelace) copied from the schema
  fixture.
- The editor preview shows only A4 pages, laid out in the user's browser at a
  CSS zoom. Its line and page breaks can differ from the server PDF. The
  product promise allows only page-break placement to differ.
- Library cards show page one of each sample as a scaled page. The template
  page shows the continuous web page inside a paper frame.
- The resume's narrow layout switches on the window width, so a narrow editor
  pane on a desktop still gets the desktop layout.

## Release order

| Release | Outcome                         | Acceptance                                                                                                                                                                                                                                                  |
| ------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| v0.5.0  | Homepage sample from the owner  | The homepage shows a one-page developer resume for "Danny" with the owner's GitHub avatar. Employer names are replaced by neutral descriptions. The sample stays schema-valid and renders on phone and desktop.                                             |
| v0.5.1  | Preview and PDF gap measured    | A CI check renders the samples in English and Vietnamese as the in-browser page preview (Chromium and WebKit) and as the server PDF, compares line and page breaks, and reports the cause of each difference. No UI change.                                 |
| v0.5.2  | Editor page preview fixed       | Fix the preview zoom and page margins that v0.5.1 shows to differ. The v0.5.1 check passes for Chromium within the product promise.                                                                                                                        |
| v0.5.3  | Editor PDF and Web modes        | The editor preview has "PDF" (default) and "Web" modes in both languages. The resume's narrow layout switches on its container width, so the Web mode matches the reader's device and the public page is unchanged.                                        |
| v0.5.4  | Exact PDF in the editor         | A button in the PDF mode shows the server-rendered PDF of the current revision, with a per-account rate limit.                                                                                                                                             |
| v0.5.5  | Sample PDFs built at release    | A release step renders each gallery sample's PDF and page images through the server renderer. A CI check fails when the stored images differ from a fresh render. No UI change.                                                                            |
| v0.5.6  | Library cards show PDF pages    | Gallery cards show the stored page images, with alt text.                                                                                                                                                                                                  |
| v0.5.7  | Template page PDF and Web modes | The template page has "PDF" (default, stored page images) and "Web" (continuous HTML) modes. Search engines still read the HTML.                                                                                                                           |

From v0.5.8, review each template's preview and update its styles and sample
content, one template per release. The link-preview releases planned for v0.4
wait until the owner schedules them.

## Rules

- One feature per release; each release deploys on its own after green CI.
- v0.5.2 depends on v0.5.1, and v0.5.6 and v0.5.7 depend on v0.5.5.
- The homepage sample uses the owner's approved content. Tests and other
  fixtures stay fictional.
