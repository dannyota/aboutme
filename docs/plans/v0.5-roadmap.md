# v0.5.x roadmap

Theme (owner, 2026-09-24): users see what readers get. One resume renders as a web page that adapts to the reader's device and as an A4 PDF. The editor and the template library show both forms, and the PDF view matches the downloaded file. Releases take numbers in shipping order; [README](README.md) lists what each tag shipped.

## Done

- Homepage sample from the owner (v0.5.0; one-sheet fits in v0.5.1 and v0.5.3).
- Editor "PDF" and "Web" preview modes with a container-width narrow layout (v0.5.2): `apps/web/app/components/editor/EditorPreview.vue`.
- Gallery sample PDF page images and a CI check that fails when they go stale (v0.5.2): `apps/web/public/templates/pages/`, `apps/web/e2e/sample-pages.spec.ts`.
- Preview-to-PDF gap check in Chromium and WebKit, both languages, and the zoomed-preview re-pagination fix (v0.5.3), and list spacing kept when a split entry continues on the next page, with tightened ceilings (v0.5.4): `apps/web/e2e/preview-gap.spec.ts`.

- Library cards show the stored sample page images (v0.5.11); template pages have Page, PDF, and What an ATS reads tabs (v0.5.12).
