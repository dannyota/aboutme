# P5B adversarial coverage

Each case belongs to its named task author. The phase reviewer checks the
integrated result; there is no separate adversarial-test worker.

| Risk                                                                     | Required proof                                                                                                                                                                                                    | Owner    |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Dirty or dispatching editor                                              | Publish flushes first and cannot race an older accepted revision                                                                                                                                                  | T01, T03 |
| Conflict, partial template, opaque media, read required, or session loss | Publish stays blocked with a fixed recovery state                                                                                                                                                                 | T01, T02 |
| Forged or rotated CSRF                                                   | At most one `/me` refresh and one same-attempt retry; a second rejection stops                                                                                                                                    | T01      |
| Network loss or `500` after commit                                       | Explicit retry retains the exact UUID idempotency key and frozen body                                                                                                                                             | T01      |
| `412 revision_mismatch`                                                  | Validated winner is adopted; no automatic publish replay occurs                                                                                                                                                   | T01      |
| `409 slug_taken`                                                         | Fixed local copy preserves the user's dialog state for a new choice                                                                                                                                               | T01, T02 |
| `409 idempotency_key_reuse`                                              | Closed failure; never synthesize a key and repeat the uncertain action                                                                                                                                            | T01      |
| `422 publish_invalid`                                                    | Only validated path/code pairs enter UI state; malformed issues fail closed                                                                                                                                       | T01, T02 |
| `403 reauth_required`                                                    | Password users retain the frozen intent through wrong/success cases; provider-only users get only the enabled stable-first provider, an allowlisted top-level new-tab URL, and an explicit post-round-trip retry  | T01, T02 |
| `429` or `503`                                                           | Honor a valid `Retry-After`, reject malformed values, and never busy-loop                                                                                                                                         | T01, T02 |
| Invalid or hostile slug                                                  | Local ASCII grammar rejects obvious invalid input; server handles reserved, claimed, and tombstoned slugs; Vue renders text, never HTML                                                                           | T01, T02 |
| Dependent flags while private                                            | Turning Public resume off also turns PDF download and SEO/GEO off                                                                                                                                                 | T02      |
| Duplicate keyboard/pointer submit                                        | One frozen request can be in flight; busy controls cannot dispatch another                                                                                                                                        | T01, T02 |
| Modal keyboard/focus behavior                                            | Label, initial focus, Escape, focus return, error announcement, and issue-focus transition are deterministic                                                                                                      | T02, T03 |
| Unaccepted public link                                                   | Link comes only from canonical accepted metadata, never raw slug input                                                                                                                                            | T02      |
| Cache/revocation lag                                                     | Native HTTPS proof observes unpublish `404` in at most five seconds                                                                                                                                               | T03      |
| Evidence disclosure                                                      | Proof records presence/status/bounds only; no cookie, token, key, password, body, or personal data                                                                                                                | T03      |
| Agent authority expansion                                                | Generated client may know the route, but MCP exposes no publish, unpublish, or public-read tool                                                                                                                   | T03, T04 |
| Scope creep                                                              | Reuse provider reauth only for the supported provider-only rename case; add no provider endpoint, identity-management scope, SSE, public PDF/image renderer, clipboard feature, list status, or public Nuxt route | T01–T04  |
