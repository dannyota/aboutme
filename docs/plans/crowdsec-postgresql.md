Status: in progress. The host migration, catalog gate, bounded retention, seven-field feed, and privacy notice are implemented. The [runbook](../runbooks/crowdsec-postgresql.md) owns operator commands; the [privacy design](../design/crowdsec-http-privacy.md) owns behavior.

- Obtain independent adversarial review of the host migration and explicit reset, including interrupted provisioning, private registration, failure stops, timer order, and ordinary deploy integration.
- Obtain independent review of the notice backend, bilingual legal copy and publication-date digest, and host send/activation and restore fences against the [required proof matrix](../design/crowdsec-privacy-notification.md#security-and-required-proof). Include cohort capture, mail/deletion races, receipt and epoch validation, adoption, mount checks, lock ownership, crash recovery, and ambiguous completion.
- Run `make pre-push` in the primary session and require green GitHub CI on the exact candidate. Include the migration ordering test, PostgreSQL catalog and reset tests, real-consumer retention, notice backend and host proofs, bilingual legal tests, both web browser shards, deployment safety, and workflow contracts. Require the server, server-integration, web, VN infrastructure, and contracts jobs as part of aggregate CI.
- Resolve every review and CI defect, then land through the ordinary pull request flow.
- Publish and deploy one eligible patch release through the ordinary deployer. Preserve the completed privacy-notice activation and the release floor.
- Verify the deployed database identity, peer map, connection limits, catalog policy, current retention lease, enabled and active timers, scheduled vacuum, local API, bouncers, and public enforcement without retaining attack values.
- Record aggregate production resource, sensitive error-sink, runtime egress, backup inclusion, and expiry evidence under the existing acceptance rows. Never retain request values, credentials, or database rows in reports.
- Keep reset after a cluster restore as an explicit operator action. Record a reviewed reset proof that replaces only the CrowdSec database and preserves application state.
- Verify new, replacement, and drill hosts install the shared notice helpers and fixed restore controller before any restore and preserve authority state through later full installation. Complete independently reviewed operator recovery procedures for unknown final-release or SSH outcomes under the [restore fence contract](../design/crowdsec-privacy-notification.md#send-authority-and-restore-fence). A full-host restore controller needs its own reviewed database procedure and entry point before use.
