# AC-MEDIA traceability rows

Nine planned acceptance criteria own private resume-photo intake and lifecycle.
See [README.md](README.md) for matrix rules.

| ID           | Design clause             | Statement                                                                                                                                                                                                                                                                                                                                          | Phase/task        | State   | Test / acceptance reference                                         |
| ------------ | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ------- | ------------------------------------------------------------------- |
| AC-MEDIA-001 | API: photo intake         | Upload is owner-only; accepts one raw multipart file within the exact request and file byte ceilings; selects static JPEG, PNG, or WebP by decoder; and rejects transport, size, or type failures before any object write                                                                                                                          | P2B T11           | PLANNED | P2B T11 and blind suite F                                           |
| AC-MEDIA-002 | ADR 0019                  | Object keys are server-derived, traversal-safe, immutable, unguessable, and unaffected by request fields, filenames, input types, or metadata                                                                                                                                                                                                      | P2B T3/T11        | PLANNED | P2B T3/T11 and blind suite F                                        |
| AC-MEDIA-003 | ADR 0019                  | Crop changes preserve the server-owned key with no object I/O; replacement clears the old crop; photo replace, photo delete, and resume delete remove the database reference before deleting exact canonical old bytes; malformed or cross-resume keys never reach a backend; live data never points to an object intentionally removed by cleanup | P2B T3/T6/T11/T14 | PLANNED | Backend exact-key, crop, CRUD cleanup, lifecycle, and blind tests   |
| AC-MEDIA-004 | Deployment: media         | Filesystem and S3 backends pass one contract and full lifecycle suite; the S3 gate fails closed when its service is absent; storage credentials never enter client responses or logs                                                                                                                                                               | P2B T3/T11/T12    | PLANNED | Backend conformance, lifecycle parity, and blind secret-leak suites |

| AC-MEDIA-006 | ADR 0019                  | Definite failures compensate; ambiguous or crash candidates stay private; cleanup cannot make live data point to absence                                                                                                                                                                                                                           | P2B T11/T14       | PLANNED | Failure-injection suite                                             |
| AC-MEDIA-007 | ADR 0019                  | The 48-hour orphan sweep deletes only unreferenced objects and enforces its page, run, retry, concurrency, cursor, metric, and dry-run rules                                                                                                                                                                                                       | P8-priv           | PLANNED | Scheduled-job acceptance gate                                       |
| AC-MEDIA-008 | API: photo intake         | Intake applies valid Exif orientation, rejects animation and unsafe structure, strips source metadata and profiles, rejects trailing data, and stores only a deterministic bounded JPEG or PNG                                                                                                                                                     | P2B T11/T14       | PLANNED | Normalizer and blind canonical-output suites                        |
| AC-MEDIA-009 | Security: untrusted media | Source dimensions and pixel count, task-wide admission, cancellable read/write deadlines, synchronous normalization release time, and measured peak memory obey the exact budgets; rejection leaves no work or write behind                                                                                                                        | P2B T11/T14       | PLANNED | Frozen resource benchmark and blind admission suite                 |
