# AC-REN traceability rows

8 acceptance-criterion rows with the `AC-REN-` prefix, in their original matrix
order (007 and 008 minted 2026-08-11 for the templates spec's accessibility
floor and its new optional tokens). See [README.md](./README.md) for the matrix
purpose, maintenance rules, and the full prefix index.
