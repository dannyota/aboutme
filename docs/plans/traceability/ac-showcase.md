# AC-SHOW traceability rows

Fifteen acceptance-criterion rows use the `AC-SHOW-` prefix, for the community
showcase ([design](../../design/showcase.md),
[ADR 0029](../../adr/0029-community-showcase.md)). The owner approved S1 to S13
on 2026-09-27. The showcase is built: thirteen rows are `LANDED` with the tests
that cover them, and the two rows that need a production launch step are
`PLANNED`. A `LANDED` row moves to `PROVEN` once GitHub CI passes its tests on
the release commit and the row names no other gap. See [README.md](./README.md)
for matrix rules and the full prefix index.
