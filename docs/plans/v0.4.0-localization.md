# Resume workspace localization implementation plan

Status: planned. The owner approved the product scope on 2026-09-20. Product
work starts after the accepted design record lands on `main`.

**Goal:** Ship v0.4.0 with a complete Vietnamese and English resume workspace,
while interface language remains independent from every resume value.

**Architecture:** Extend the existing `Locale`, cookie, and typed copy-map
pattern. Controllers and composables retain semantic states and codes.
Components choose copy reactively. Route-specific catalogs keep workspace copy
out of public-render and print bundles.

**Tech stack:** Nuxt 4, Vue 3, TypeScript, Vitest, Playwright, and the existing
native HTTPS harness.

**Spec:** [Resume workspace localization](../design/editor-localization.md),
[ADR 0047](../adr/0047-bilingual-resume-workspace.md), `AC-EDITOR-018`, and
`AC-UI-014`.

## Global constraints

- Reuse `Locale = 'vi' | 'en'`, `aboutme-locale`, `useLocale()`, and
  `useRouteLocale()`.
- `/app/resumes`, `/app/new`, and `/app/resumes/{id}` use interface locale.
  Settings, account destinations, and `/authorize` remain English.
- Each surface exports `Record<Locale, SurfaceCopy>` with identical typed keys.
- Copy selection happens in components. Stores, controllers, commands, URLs, API
  payloads, and resume documents retain semantic values and codes.
- A locale toggle must not remount the editor, send a write, change a revision,
  change resume language, replace user content, or clear a dirty draft, dialog,
  focus, selection, conflict, or pending command.
- A blank start captures interface locale once when its flow opens. A sample's
  explicit language wins. A later toggle changes only interface copy.
- Preserve user text, template names, language tags, URLs, codes, identifiers,
  test hooks, the `DELETE` token, and the pure renderer.
- Add no runtime package, API, schema, renderer, migration, or server change.
- Use fictional test data. Never use the owner's production account.
- Only the manager performs Git operations. Workers do not add, commit, stash,
  reset, switch branches, or create worktrees.
- Every worker starts with `git status --short`, treats existing changes as
  belonging to another task, writes the failing test first, and stops for a
  contract conflict or overlapping ownership.
- Code, tests, and living docs must not cite this plan or its task numbers. Use
  the design, ADR, or acceptance ID. Write short plain text with no em dash.
- One database container may run. Do not stop it. Run no more than three heavy
  checks at once. Do not run local `make ci` unless diagnosing CI.

## Copy interfaces

Task 1 creates these shared interfaces before any other product task starts:

```ts
export type WorkspaceCopy<T extends object> = Readonly<
  Record<Locale, Readonly<T>>
>;

// LocaleToggle.vue
defineProps<{
  readonly label: string;
  readonly testId: "landing-locale" | "workspace-locale";
}>();
```

Each later catalog declares its own named `SurfaceCopy` type and exports a
`WorkspaceCopy<SurfaceCopy>`. Interpolated values use typed functions in that
copy type and render through Vue text bindings. No copy function returns HTML.

Task 2 changes stored list notices to these semantic values:

```ts
export type CreateNotice =
  "resume-cap" | "create-failed" | "retry-later" | "session-lost" | null;
export type ResumeListNotice = "resume-changed" | null;
export function createNotice(result: CreateResumeResult): CreateNotice;
```

Task 6 changes PDF state to this semantic value:

```ts
export type PdfDownloadError =
  | "save-required"
  | "session-lost"
  | "download-failed"
  | "temporarily-unavailable";
export type PdfDownloadState =
  | { readonly kind: "idle" }
  | { readonly kind: "pending" }
  | { readonly kind: "error"; readonly code: PdfDownloadError };
```

## Review focus

- Invalid or absent locale cookies select Vietnamese on scoped routes and do not
  select a module, URL, redirect, or HTML fragment. Task 1 owns the test.
- Toggling locale during blank or sample creation preserves the captured
  language, title, sample, document, and submitted bytes. Task 2 owns the test.
- Toggling locale with dirty input, focus, an open dialog, a conflict, and a
  visible error changes shown copy without a write or revision change. Tasks 3
  and 4 own unit tests. Task 8 owns the integrated browser proof.
- Known issue codes map to safe localized copy. Unknown codes use a generic
  localized message and never expose server text or HTML. Tasks 3 and 6 own the
  tests.
- Vietnamese and English publish and PDF pending, blocked, rate-limited,
  session-ended, uncertain, retry, and success states preserve command and
  returned-byte behavior. Task 6 owns the tests.

## Integrated release gate

After all author tasks and fixes, dispatch the fresh integrated reviewer. Any
finding returns to the author that owns the path. The same reviewer confirms
fixes.

The manager then:

1. Runs `make web-e2e` in a clean worktree at the release commit and confirms no
   renderer or public baseline changed.
2. Pushes the v0.4.0 release commit alone to `main`.
3. Waits for green GitHub CI on that exact commit.
4. Tags `v0.4.0`, waits for release images, runs the production `tofu plan`, and
   stops on any unexpected destroy.
5. Deploys with `deploy/aws/scripts/deploy.sh v0.4.0`.
6. Verifies the Vietnamese phone and desktop journey, checks English, and
   confirms one saved resume is byte-for-byte unchanged after locale toggles.

The manager records the base and candidate total client JavaScript bytes with:

```bash
find apps/web/.output/public/_nuxt -type f -name '*.js' -printf '%s\n' \
  | awk '{ total += $1 } END { print total + 0 }'
```

The reviewer inspects chunk imports and rejects any workspace catalog imported
by a public-render or print entry. There is no approved size budget to invent;
the report records the exact delta.
